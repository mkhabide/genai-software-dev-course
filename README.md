# genai-software-dev-course

## Repository structure

- [`01-genai-applications-research/`](01-genai-applications-research/) contains the generative AI applications research report and its vocabulary usage graph.
- [`docs/`](docs/) contains course vocabulary and other learning reference materials.

The `docs/` folder is kept separate from numbered practical tasks, such as task 01, **GenAI Applications**, so shared learning references can be updated and expanded throughout the course without tying them to a single task.
